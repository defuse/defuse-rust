Online password generators like the one above are convenient, but you must trust the web server not to be compromised and/or misconfigured in a way that puts your passwords at risk. A more secure option is to generate passwords locally, on your computer, using the high-quality cryptographic random numbers that your operating system provides. On this page, you'll find a command-line utility and Windows app that let you do exactly that.

Windows Password Generator

Source Code on GitHub
Download WinPassGen.exe

The Windows GUI version combines data from the Cryptographically Secure Random Number Generator (CSPRNG) built into Windows with random mouse movements and other system information (CPU usage, memory usage, high-precision timers, etc.) to produce extremely secure passwords that are completely unique to you.

This version runs on Windows XP, Windows Vista, Windows 7, Windows 2000, and Windows Server 2003+.

ZecSec: Zcash Ecosystem Security

ZecSec is a project dedicated to security auditing, research, and vulnerability disclosure for the Zcash ecosystem. The goal is to improve the security and privacy of Zcash wallets, libraries, and related infrastructure through independent audits and public reporting.
